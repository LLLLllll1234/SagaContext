# Codex 记忆机制学习可视化设计

## 目标

读取用户本地 Codex 源码与会话数据，以只读、可追溯的方式展示上下文压缩、短期记忆滚动和长期记忆写入过程，帮助用户理解当前本地版本的实际行为。

## 范围

首期支持 Codex：源码参考目录可配置，默认识别本地 checkout；会话读取器从 `~/.codex/sessions` 读取。版本解析优先使用源码 commit 与可执行文件版本，无法确认时标记未知。页面默认展示摘要，点击事件后查看经过脱敏的原文。

## 页面与事件

页面包含总览、会话回放、压缩检查器、长期记忆检查器和源码对照。统一事件包含时间、会话、类型、摘要、来源文件/行号、证据等级和可选原文。事件类型包括消息追加、上下文快照、压缩开始/结束、摘要生成、记忆候选、记忆写入/跳过、召回和取代。

## 边界与验证

所有读取 API 只读本地文件与 Ledger，不调用写入、Judge 或后端检索。解析失败保留为未解析事件并说明原因。Codex 原生行为、SagaContext 记忆写入和页面推断分别标注。使用脱敏 fixture 覆盖版本差异、压缩、截断和坏文件，并以一份真实本地会话人工核对时间顺序、token、源码定位和记忆链路。
