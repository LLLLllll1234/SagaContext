# Memory Asset Center 实现计划

## 目标

把现有 Memory Lab 的资产页改成“内容 + 生命周期”的主工作台，并保持 Codex/Claude 产品隔离及证据等级标注。

## 步骤

1. **资产卡片重排**：在 `memlab.js` 的 `views.codex.assets` 中，将标题/摘要置于首行，增加来源会话数、引用次数、最近活动和生命周期状态徽章。
2. **生命周期摘要**：复用 `/api/codex/lifecycles` 数据，为每个资产计算形成、写入、召回、取代/遗忘的状态摘要；缺失信息显示未知并标 inference。
3. **详情抽屉升级**：扩展 `showAsset`，增加四段生命周期轨道、证据定位和回到形成过程/短期上下文的按钮。
4. **总览入口**：在总览增加最近资产活动与“进入资产中心”按钮，避免底层事件成为首屏主对象。
5. **视觉与响应式**：补充资产卡片网格、状态轨道和空数据样式，复用现有 CSS 变量，不引入构建步骤。
6. **验证**：运行 memlab 相关测试，启动本地服务检查 Codex/Claude 切换、抽屉、深链和无数据场景。

## 风险控制

- 仅使用现有 GET API，不触发写入、Judge 或后端检索。
- 不改变已有事件解析和证据等级语义。
- 先保留现有列表 DOM 兼容选择器，再逐步替换视觉结构。
